# Hritik's Personal Portfolio

Welcome to my personal portfolio repository! This site showcases my projects, skills, and open-source contributions. 

Built with [Next.js](https://nextjs.org), [React](https://react.dev), and [Tailwind CSS](https://tailwindcss.com).

## ✨ Features

- **Modern UI**: Clean and responsive design.
- **Projects Showcase**: Highlighting my work and launched products.
- **GitHub Integrations**: Displays GitHub stats and activity heatmap.
- **Dark/Light Mode**: Built-in theme picker.
- **Tech Stack**: Fast and optimized with the latest Next.js App Router.

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📁 Project Structure

- `/src/app` - Next.js App Router pages and layouts.
- `/src/components` - Reusable UI components (Hero, Nav, Projects, Skills, etc.).
- `/public` - Static assets.
